# Read-only six-profile signal evidence export

An ordinary review ZIP contains ledger summaries, status and log tails, but deliberately excludes candle journals. Empty recorded entry-review counters and ledgers can locate observed inactivity before the instrumented entry review; they do not independently prove that strategy inputs, normalization, indicators and source signal evaluation are correct. Candle evidence is needed to reproduce that evaluation.

`tools/export-crypto-signal-evidence.ps1` creates an isolated review checkout and runs the standard-library export tests. It does not merge into installed Atlas, replace any launcher, stop/start a worker, clear a pause, change a threshold, request market data, invoke Grok, or submit an order. The Windows Atlas Python is sufficient; no Docker or additional dependency is needed for the export.

The PowerShell exporter requires the ordinary review ZIP as an anchor. It selects each of the five fleet recordings and original NFI recording by the exact identities and written checkpoints in that review, even if a worker has since restarted or appended more data. The fleet identity must match. Reviewed metadata is retained and the source configuration must still match the selected baseline. The Python module also supports a current-recording mode, using its recording pointer checked against runtime identity, when no reference review is supplied. It copies exactly the selected already-written record prefix into the ZIP. Every exported record is checked for sequence, schema, baseline identity, previous hash and canonical SHA256. Record count, byte count and final chain head must match the selected checkpoint. Append activity and an unfinished trailing line after that anchor are excluded; they are not treated as data loss. No writer is paused to obtain the snapshot.

The archive contains original journal records (raw public OHLCV, native candles and signals, entry reviews and any captured order responses), checkpoint anchors, exact local strategy/source files, configuration/profile metadata and per-file hashes. NFI baseline binding uses its resolved configuration; fleet profiles use their sealed configuration. It rejects a changed configuration, unsafe recording pointer, mismatched current recording, broken prefix, over-limit record or source link. A failed export deletes its partial archive and preserves original evidence.

The result is explicitly a verified written prefix, not a closed full-session journal audit. Each worker has its own checkpoint time. Writer health, source completeness and capacity flags remain separate from cryptographic integrity; an incomplete source is labeled, never certified complete by the export. These are private research artifacts and must not be published to GitHub.

The exported data enables the next offline audit: verify the downloaded strategy identities and effective native settings; reconstruct observed candle inputs and timing; reproduce source evaluations; compare source BUYs with recorded signals; and measure unmet entry conditions. Do not assume a rolling-window reconstruction exactly matches every cached input when the journal did not record that cache version. Do not change rules or force trades merely to obtain a nonzero sample.

Validation: twelve disconnected standard-library tests cover six-worker export without network calls or source mutation, partial append exclusion, segment sequencing, tamper refusal and partial-output cleanup, independent checkpoint count/byte/head checks, changed configuration, recording pointer/transition refusal, incomplete-source labeling preservation of existing output files, review-pinned recording selection after a restart, review-prefix append exclusion and rejection of another fleet’s review. A representative 16,212-record / 125 MB journal stress test also verifies bounded streaming and compression. PowerShell is not available on the cloud host; the script runs the same tests on the user's Windows Python before reading the actual recordings. Actual overnight candle replay remains pending that private evidence upload.
