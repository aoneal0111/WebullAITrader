# Shared market workstation

Equity is the reference layout. Crypto, Futures and Options now instantiate the same DashboardPage, MarketWorkspace, RuntimeControlHeader, PositionsPanel, OrdersPage, ActivityPanel, DecisionsPanel, WatchlistPanel, ReplayPage and PortfolioSummaryStrip components. Navigation changes the selected market's page, rather than opening a separate crypto monitor or replacing Mission Control with a derivatives calculator.

The account/risk strip lives below the page stack. It stays visible on Mission Control, Positions, Orders, Operator Workspace, Decisions, Activity, Scanner, Replay and Settings. Equity portfolio cards continue updating on all routes without rendering the detailed Operator Workspace portfolio on hidden pages. Market-specific status bars and sidebar connection text prevent Equity status from appearing as Crypto/Futures/Options status.

Crypto reads the existing independent Docker PAPER wallets through CryptoMonitorReader. A wallet selector changes positions, closed trades, working orders, native stop levels when persisted, realized P/L and source health together. Wallet balances are not added together. Account realized P/L includes closed-lifecycle net plus reported realized partials in open lifecycles; open inventory is not counted as a win. Current equity, cash, broker buying power, market value and unrealized P/L remain unknown because the monitor does not have those authoritative valuation feeds. Small token prices retain their actual fractional precision in the shared order and position widgets.

Futures and Options use their existing bounded, read-only saved-ledger readers. Saved cash, realized P/L, contract positions, stop/target plans and events remain distinguishable from current quotes, broker orders and worker availability. Simulator events are Activity records, not fabricated working orders. Existing scenario calculation modules remain available; this change does not connect a feed or enable trading.

Data refresh runs on a bounded background read task, at most one per visible workspace. Navigation does not subscribe to a provider, start a market, restart a Docker container, execute a model request or submit an order. Controls that have no execution adapter stay disabled. Hidden market workspaces stop their refresh timers. Failed reads clear prior data rather than displaying another wallet's or market's values. The standalone crypto diagnostic monitor remains available but is no longer the main tab implementation.

The installer requires Atlas to be closed, verifies the existing continuous PAPER spec, runs GUI and reader checks with isolated Qt settings, backs up the code branch, and updates the code without rewriting the existing operating spec, launchers, ledger or strategy settings. Atlas stays stopped. The Warrior full-library/partial-harvest repair remains installed.

Validation: 251 GUI and reader checks passed locally with isolated Qt settings. Validation covers all market/sidebar routes retaining the same footer, no runtime activation from navigation, separate wallet totals, unknown-data states, current-source liveness, saved contract balances, small-price precision, existing Equity layout and order behavior, and read-only WAL-aware crypto ledger monitoring. Offscreen screenshots of all four Mission Control views were inspected at 1600×1000; Windows font metrics and the connected data sources still need local review.
